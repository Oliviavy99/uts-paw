- Terdapat informasi film atau serial
- Terdapat fitur searching buat mencari film atau serial

## Menjalankan secara lokal

cd app
npm install
npm run dev

## Konsep React yang dipakai

- Component: untuk memecah tampilannya menjadi beberapa bagian supaya lebih mudah.
- Context: berisi koleksiContext.js dan koleksiProvider.jsx untuk mengatur data koleksi.
- hooks: berisi useKoleksi.js dan useLocalStorage.js untuk mengakses dan menyimpan data.
- pages: berisi halaman Beranda, koleksi, tambah, statistik, tentang.
